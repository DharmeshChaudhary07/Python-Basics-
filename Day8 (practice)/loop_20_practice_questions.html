Easy — Q1 to Q8
Q1easyfor loop
Print odd numbers
Print all odd numbers from 1 to 15.
A number is odd if number % 2 != 0. You can also use range(1, 16, 2) to step by 2.
for i in range(1, 16): if i % 2 != 0: print(i)
Q2easyfor loop
Print each character of a string
Ask the user for their name. Print each character on a new line using a for loop.
Strings are iterable. You can loop directly: for char in name — no range() needed.
name = input("Enter your name: ") for char in name: print(char)
Q3easywhile loop
Double until over 100
Start with n = 1. Keep doubling it using a while loop and print each value until it exceeds 100.
Loop while n <= 100. Inside, print n then set n = n * 2.
n = 1 while n <= 100: print(n) n = n * 2
Q4easyfor loop
Sum of even numbers
Find and print the sum of all even numbers from 1 to 50.
Use total = 0 before the loop. Inside, check if i % 2 == 0, then add to total.
total = 0 for i in range(1, 51): if i % 2 == 0: total += i print(total)
Q5easyfor loop
Repeat a word
Ask the user for a word and a number n. Print that word n times using a for loop.
Use range(n) to loop n times. Each iteration just prints the word.
word = input("Enter a word: ") n = int(input("How many times? ")) for i in range(n): print(word)
Q6easywhile loop
Keep asking until "quit"
Keep asking the user to enter something. Stop the loop only when they type "quit".
Use while True. Read input each iteration. If the input equals "quit", break.
while True: text = input("Enter something (or quit): ") if text == "quit": break print("You entered:", text)
Q7easyfor loop
Count down by 3
Print numbers from 30 down to 0, counting down by 3 each time (30, 27, 24 ... 0).
range() has a third argument for step. range(30, -1, -3) counts down by 3 and includes 0.
for i in range(30, -1, -3): print(i)
Q8easyfor loop
Count vowels in a word
Ask the user for a word. Count and print how many vowels (a, e, i, o, u) it contains.
Loop through each character. Check if the char is in the string "aeiou". Use a counter variable.
word = input("Enter a word: ").lower() count = 0 for char in word: if char in "aeiou": count += 1 print("Vowels:", count)

Q9mediumfor + if
Prime number check
Ask the user for a number. Check if it is prime (divisible only by 1 and itself) and print the result.
Loop from 2 to n-1. If any number divides n evenly (n % i == 0), it is not prime. Use a flag variable is_prime = True before the loop.
n = int(input("Enter a number: ")) is_prime = True for i in range(2, n): if n % i == 0: is_prime = False break if is_prime and n > 1: print(n, "is prime") else: print(n, "is not prime")
Q10mediumwhile + try/except
Safe number input
Keep asking the user to enter a number. If they type something that is not a number, print "Invalid! Try again" and ask again. Stop when they give a valid number.
Use while True with try/except ValueError inside. If int(input()) fails, the except block runs. If it succeeds, break out.
while True: try: n = int(input("Enter a number: ")) break except ValueError: print("Invalid! Try again")
Q11mediumfor + if
Find the largest number
Ask the user to enter 5 numbers one by one using a loop. After all 5 are entered, print the largest one.
Keep a variable largest = None. Each loop, compare the new number with largest and update if it is bigger.
largest = None for i in range(5): n = int(input("Enter number: ")) if largest is None or n > largest: largest = n print("Largest:", largest)
Q12mediumfor loop

word = input("Enter a word: ") result = "" for i in range(len(word)-1, -1, -1): result += word[i] print(result)
Q13mediumwhile + counter
Login with 3 attempts
Set a password = "python123". Give the user 3 attempts to guess it. Print "Access granted" or "Locked out" based on the result.
Use a counter attempts = 0. Loop while attempts less than 3. Increment counter each time. Break early if correct.
password = "python123" attempts = 0 while attempts < 3: guess = input("Enter password: ") attempts += 1 if guess == password: print("Access granted") break else: print("Locked out")
Q14mediumfor + if
Count positive and negative
Ask the user to enter 6 numbers. Count how many are positive and how many are negative. Print both counts at the end.
Keep two counters: pos = 0 and neg = 0. Inside the loop, check if n > 0 or n < 0 and increment accordingly.
pos = 0 neg = 0 for i in range(6): n = int(input("Enter number: ")) if n > 0: pos += 1 elif n < 0: neg += 1 print("Positive:", pos) print("Negative:", neg)
Q15mediumnested for
All multiplication tables
Print multiplication tables for numbers 1 through 5. Each table goes from x×1 to x×10.
Use two nested for loops. Outer loop: i from 1 to 5 (the table number). Inner loop: j from 1 to 10 (the multiplier).
for i in range(1, 6): print(f"--- Table of {i} ---") for j in range(1, 11): print(i, "x", j, "=", i*j)
Q16mediumfor + continue

1 2 3 4
1 2 3 4 5
Outer loop: i from 1 to 5 (row number). Inner loop: j from 1 to i. Print j with end=" " to keep on one line. After inner loop, print() for a new line.

Q18hardwhile + logic
Collatz conjecture
Ask for a number n. If it is even, divide by 2. If odd, multiply by 3 and add 1. Repeat until n reaches 1. Print each step and count how many steps it took.
Use while n != 1. Inside: check if n % 2 == 0 for even, else do n = 3*n + 1. Keep a steps counter and increment each loop.
n = int(input("Enter a number: ")) steps = 0 while n != 1: print(n) if n % 2 == 0: n = n // 2 else: n = 3 * n + 1 steps += 1 print("Reached 1 in", steps, "steps")
Q19hardfor + logic
Fibonacci sequence
Print the first 15 numbers of the Fibonacci sequence (0, 1, 1, 2, 3, 5, 8...) using a loop.
Start with a = 0, b = 1. Each iteration: print a, then update a and b together — new_b = a + b, a = b, b = new_b.
a = 0 b = 1 for i in range(15): print(a) a, b = b, a + b
Q20hardwhile + full logic
Mini calculator loop
Build a calculator that keeps running. Each round ask the user for two numbers and an operator (+, -, *, /). Show the result. If the user types "quit" as the operator, stop the program.
Use while True. Read two numbers and an operator each loop. Use if/elif to perform the right operation. Handle division by zero. Break when operator is "quit".
while True: op = input("Operator (+, -, *, /) or quit: ") if op == "quit": break a = float(input("First number: ")) b = float(input("Second number: ")) if op == "+": print(a + b) elif op == "-": print(a - b) elif op == "*": print(a * b) elif op == "/": if b == 0: print("Cannot divide by zero") else: print(a / b) else: print("Unknown operator")
