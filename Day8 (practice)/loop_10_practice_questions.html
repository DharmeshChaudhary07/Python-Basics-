Q1easyfor loop
Print 1 to 10
Print all numbers from 1 to 10, each on a new line using a for loop.
range(1, 11) gives you 1 through 10. range(10) starts from 0 — watch the difference.
for i in range(1, 11): print(i)
Q2easyfor loop
Sum of 1 to 100
Calculate and print the sum of all numbers from 1 to 100 using a for loop.
Start with total = 0 before the loop, then add each i to total inside the loop.
total = 0 for i in range(1, 101): total = total + i print(total)
Q3easywhile loop
Countdown from 10
Print a countdown from 10 down to 1 using a while loop. Print "Go!" at the end.
Start n = 10, loop while n >= 1, print n, then subtract 1 from n each iteration.
n = 10 while n >= 1: print(n) n = n - 1 print("Go!")
Q4easyfor loop
Multiplication table of 5
Print the multiplication table of 5 from 5×1 to 5×10. Each line: 5 x 1 = 5
Loop i from 1 to 10. Inside the loop print: 5, "x", i, "=", 5*i
for i in range(1, 11): print(5, "x", i, "=", 5*i)
Q5mediumfor + if
Print even numbers
Print only the even numbers between 1 and 20. Use a for loop with an if condition inside.
A number is even if number % 2 == 0. The % operator gives the remainder after division.
for i in range(1, 21): if i % 2 == 0: print(i)
Q6mediumfor + if
FizzBuzz
Print numbers 1 to 30. Print "Fizz" for multiples of 3, "Buzz" for multiples of 5, "FizzBuzz" for multiples of both — otherwise print the number.
Check FizzBuzz condition first (both 3 and 5), then Fizz, then Buzz, then the number. Order matters here!
for i in range(1, 31): if i % 3 == 0 and i % 5 == 0: print("FizzBuzz") elif i % 3 == 0: print("Fizz") elif i % 5 == 0: print("Buzz") else: print(i)
Q7mediumwhile + break
Number guessing game
Set secret = 7. Keep asking the user to guess a number. Print "Try again" until they get it right, then print "Correct!" and stop.
Use while True to loop forever. Use break to exit when guess is correct. Use int(input()) to read a number.
secret = 7 while True: guess = int(input("Guess: ")) if guess == secret: print("Correct!") break else: print("Try again")
Q8mediumfor + continue
Skip multiples of 3
Print numbers 1 to 20, but skip any number that is a multiple of 3. Use the continue keyword.
Inside the loop, if i % 3 == 0, use continue to skip to the next iteration without printing.
for i in range(1, 21): if i % 3 == 0: continue print(i)
Q9hardnested loops
Star pattern
Print this pattern using loops:
*
**
***
****
*****
The outer loop controls row number (1 to 5). You can print "*" * i to repeat the star i times in one line.
for i in range(1, 6): print("*" * i)
Q10hardwhile + logic
Factorial calculator
Ask the user for a number n, then calculate its factorial using a while loop. Factorial of 5 = 5×4×3×2×1 = 120.
Start result = 1. Loop while n > 0, multiply result by n, then decrease n by 1 each time. Print result after the loop.
n = int(input("Enter a number: ")) result = 1 while n > 0: result = result * n n = n - 1 print("Factorial =", result)
