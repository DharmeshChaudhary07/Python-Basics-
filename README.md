# Python Basics

A day-by-day collection of Python fundamentals exercises and practice material, organized as a structured learning log.

## 📂 Repository Structure

The repo is organized into folders by day, tracking progress through core Python concepts:

| Folder | Topics Covered |
|--------|-----------------|
| `Day1` | Python basics — `print()`, comments, variables, taking input, and data types |
| `Day2` | Working with strings — indexing, slicing, case conversion, searching, and validation |
| `Day3` | Numbers — the `math` module, numeric type conversion, rounding, and random number generation |
| `Day4` | Operators — comparison, logical, membership, and identity operators |
| `Day5` | Conditional statements — `if`/`elif`/`else`, inline `if`, `match` statements, and nested conditions |
| `Day6-7` | Loops — `for` and `while` loops, `break`/`continue`/`pass`, nested loops, and `for-else` |
| `Day8 (practice)` | Loop practice — a calculator project plus 10 and 20 loop-based practice questions |
| `Day9 (practice)` | Loop practice — 55 easy and medium-level loop practice questions |
| `Day10` | Functions — introduction, parameters/arguments/return values, and types of functions |
| `Day11-12` | Built-in data structures — lists, dictionaries, sets, and tuples |
| `Day13` | Exception handling, file handling (read/write), and modules & packages (including a custom package) |
| `Day14 (practice)` | Loop practice — PDF practice questions |
| `Day15 (practice)` | Loop practice — hard-level loop practice questions |

Each `Day*` folder contains the scripts and notes written while working through that stage of the course. Folders marked **(practice)** are dedicated to reinforcing concepts through extra exercises.

## 🎯 Purpose

This repository serves as a personal learning log for building a solid foundation in Python — covering the basics needed before moving on to more advanced topics like data structures, OOP, and applied projects (e.g. data engineering work).

## 🛠️ Getting Started

To run any script locally:

```bash
git clone https://github.com/DharmeshChaudhary07/Python-Basics-.git
cd Python-Basics-
python3 <folder_name>/<script_name>.py
```

**Requirements:** Python 3.9 or above
